# WasteWise Domain Services

- `containers`: inventario, geolocalización y criticidad.
- `sensors`: ingesta de lecturas y actualización de llenado.
- `routes`: priorización y generación de rutas.
- `fleet`: vehículos, conductores y estados operativos.
- `citizens`: QR, puntos y recompensas.
- `reporting`: incidencias ciudadanas con foto y geolocalización.
- `notifications`: alertas para equipos municipales.
- `analytics`: KPIs de volumen, operación e impacto ciudadano.
